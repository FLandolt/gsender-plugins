gSender plugins

Free, open-source plugins that turn a few numbers into clean, GRBL-safe G-code, with a 3D preview. No CAM software needed.

Plugins

Always check before you cut. Look at the preview, run the job in the air first, and keep a hand on the stop button. You use these plugins at your own risk.

How to use a plugin

  1. Download the zip of the plugin you want.
  2. Unzip it into gSender's plugins folder so you get plugins/<name>/gsender-plugin.json, then restart gSender.
  3. Open it from gSender's tools page, enter your numbers, check the preview and press Load to gSender.

Built on the gSender Plugin SDK. Not affiliated with Sienci Labs.
